Python Learning & Practice Repository

A hands-on journey through Python, its libraries, core concepts, and practical features, with examples and exercises.

📌 About This Project

PyForge is a personal learning repository focused on improving Python programming skills through practical examples, coding exercises, and small projects.

The goal is to build a strong understanding of Python and explore its ecosystem step by step.

🎯 Learning Goals

- Master Python fundamentals and advanced concepts.
- Understand functions, arguments, and data structures.
- Explore Python libraries and modules.
- Practice writing clean and reusable code.
- Solve programming exercises.
- Build practical projects using Python.

📚 Topics Covered

- Python Basics
- Variables & Data Types
- Conditional Statements
- Loops
- Functions
- Arguments & Unpacking
- Lists, Tuples, Sets & Dictionaries
- Modules & Packages
- Python Libraries
- Object-Oriented Programming
- Error Handling
- File Handling

More topics will be added as the learning journey progresses.

⚙️ Getting Started

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate to the project directory:

cd PyForge

Create a virtual environment:

python -m venv venv

Activate the virtual environment:

Windows:

venv\Scripts\activate

Linux / macOS:

source venv/bin/activate
